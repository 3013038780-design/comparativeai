## 取材范围

对每个议题，按以下优先级取材：

1. **一手法源**：法律、行政法规、部门规章、技术标准（含强制/推荐/指南）。
2. **官方解读**：立法说明、国新办发布会、监管机构问答、执法决定书。
3. **二手研究**：同行评议论文、智库报告、行业白皮书。
4. **舆论语料**（可选）：仅用于说明社会反馈，不作为规范性依据。

每条引用记录 **原文链接**、**发布机构**、**发布日期**、**本站访问时间**。

## 翻译规则

- 条文原文与译文左右对照，默认保留原文为准。
- 专有术语给出中英对照表（见 [立法翻译](/law-translations/)）。
- 不使用 LLM 直接产出的未校对译文；AI 辅助段落会显式标注。

## 比较框架

每个议题统一按以下维度横向比较：

| 维度 | 问题 |
| --- | --- |
| 规则层级 | 法律 / 法规 / 规章 / 标准？ |
| 适用范围 | 面向开发者、部署者、用户？境内外？ |
| 核心义务 | 具体要做什么？能否量化？ |
| 执法机制 | 谁来执法？处罚梯度？ |
| 豁免与例外 | 哪些场景不适用？ |
| 争议焦点 | 学界 / 产业界争议点？ |

## 更新流程

- 每条内容的变更记录在 Git 历史，重要变更同步到 [更新日志](/updates/)。
- 官方文件被替换或废止时，旧版本不删除，打上 `superseded` 标记。
- 欢迎通过 Issue / PR 指出错误，会在下次更新时致谢。
