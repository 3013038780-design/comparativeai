## 公司概况

- **成立**：1998
- **总部**：深圳
- **主要 AI 产品 / 品牌**：**混元 Hunyuan** 大模型家族
  - **混元大语言模型**（MoE 架构，万亿参数旗舰）
  - **HunyuanImage 3.0**（图像生成）
  - **HunyuanVideo**（视频生成，130 亿参数，**开源**）
  - **HunyuanVideo-Avatar**（语音数字人）
  - **HunyuanVideo-I2V**（图生视频）
  - **HunyuanCustom**（一致性视频）
  - **混元 3D / 3D 世界模型**（**业界首个开源可漫游 3D 场景生成**）
  - **混元 GameCraft**（游戏视频生成）
  - 混元-large-vision（多模态理解，**LMArena Vision 国内第一**）
  - 小尺寸模型（0.5B / 1.8B / 4B / 7B 推理）
- **商业模式**：
  - **消费者生态嵌入**：微信、QQ、腾讯视频、腾讯会议、游戏（王者荣耀等）
  - **腾讯云**（ToB）：混元模型 API
  - **投资组合**（Epic Games 40%、Discord、Supercell、Riot 100% 等）：被投公司技术合作

## 战略定位：**起步较晚 + 全线开源追赶**

### 起步较晚

腾讯在生成式 AI 浪潮中**起步明显晚于百度、阿里**：
- 2023 国内"百模大战"时腾讯动作较保守
- 2024 才开始混元系列密集发布
- **微信生态的护城河**让腾讯不必在消费者 AI 入口上急于下注

### 追赶策略：**多模态全线开源**

2024-2026 腾讯采取**激进开源策略**：
- **HunyuanVideo**：2024 开源（GitHub + HuggingFace），**130 亿参数，120 秒推理**
- **混元 3D 世界模型**：2025 WAIC 发布并开源 —— **业界首个可漫游 3D 场景生成开源**
- **社区下载量超 230 万**（2025 Q4 数据），**全球最受欢迎的 3D 开源模型**
- **多模态小模型系列开源**（0.5B-7B）

**开源的商业逻辑**：
- **不是靠模型 API 赚钱**（腾讯主业是广告 + 游戏 + 社交）
- 开源是**品牌和人才吸引工具**
- **云服务差异化**：通过开源生态驱动腾讯云客户使用混元 API

## 深度分析：**平台型公司的 AI 治理**

### 与其他中国公司的分类

腾讯在中国 AI 生态中是**"平台型公司 AI"**的典型，区别于：
- **纯 AI Lab**（DeepSeek、月之暗面）：模型 → API
- **国家队**（百度）：模型 → 政府 / 产业应用
- **电商云**（阿里）：模型 → 云服务变现
- **内容 + 算法**（字节）：模型 → 消费者产品
- **平台型**（腾讯）：模型 → **已有消费者生态的 AI 增强**

**治理影响**：
- 腾讯的 AI 治理**嵌入在平台治理中**（微信内容治理、游戏防沉迷、金融风控）
- **"先有平台规则、再补 AI 规则"**——而非"先有 AI 规则"
- 与字节相似但**非跨境紧张**（腾讯国内业务为主，海外业务相对低调）

### 治理压力的两个维度

**国内**：
- 微信、QQ 作为"具有舆论属性或社会动员能力"的服务，**算法推荐备案义务最重**
- 游戏业务的"未成年人防沉迷"与 AI 陪伴 / 虚拟人规则交叉
- **微信小程序 AI 应用**的合规边界（数以万计的 AI 小程序）

**海外（有限）**：
- 投资组合中的被投公司（Epic、Riot、Discord）在美国 / 欧盟独立运营
- 微信海外版（WeChat）在美国政府设备被禁
- 被 CFIUS 审视但远轻于字节

### 自律立场

腾讯在 AI 自律上的公开文档：
- **无独立安全框架**（类似其他中国公司）
- 2018 发布《腾讯人工智能伦理原则》（较早的中国企业 AI 原则之一）
- 参与 TC260 标准起草（多个）
- **开源模型伴随的技术报告**含部分安全评估披露

## 监管合规位置

- **中国**：
  - 混元系列 CAC 算法备案
  - TC260-003-2024 合规
  - **微信 / QQ / 视频号**作为中国最大平台之一，所有 AI 相关功能均涉及多重合规
  - **游戏防沉迷**与 AI 相关功能的交叉合规
  - **支付 + 金融**（微信支付）场景的 AI 应用受金融监管
- **美国**：
  - 不在美国提供消费者 AI 产品
  - 被投公司独立运营
  - CFIUS 审视但非重点
- **欧盟**：
  - 混元开源模型欧盟可下载
  - 无欧盟消费者产品
- **东南亚 / 中东**：腾讯云 + 游戏业务较深

## 公司立场速览

- **平台优先**：AI 作为现有业务增强，而非独立产品线
- **全线开源策略**：用开源作为追赶工具
- **治理依托平台既有机制**：微信内容治理、游戏防沉迷等延伸到 AI
- **政府关系稳健**：多年"科技向善"叙事与国家政策对齐
