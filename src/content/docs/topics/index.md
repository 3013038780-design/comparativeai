议题（topic）是本站的**分析单位**。每个议题下统一有 **概览 + 中国 + 美国 + 欧盟** 四个页面，
使用同一套比较框架（见 [方法论](/methodology/#inclusion)）。

议题页做**横向分析**：这三个辖区对同一个问题是怎么想的、差别在哪、争议在哪。
**具体条文**见 [顶层规则 Rules](/rules/) 和 [地方层级 Subnational](/subnational/)；议题页引用它们，不复述。
