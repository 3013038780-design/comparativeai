## 什么是前沿模型 / GPAI

- **Foundation Model**：大规模自监督训练、可适配多种下游任务的通用模型
- **Frontier Model**：能力最接近 AGI / 前沿的 foundation 模型，通常意味着高算力、大参数
- **GPAI (General-Purpose AI Model)**：EU AI Act 的法定术语（第 3(63) 条），覆盖范围略广于 frontier

三辖区对这一类的监管：**概念、门槛、义务三不同**。

## 比较速览

| 维度 | [中国](/topics/frontier-gpai/china/) | [美国](/topics/frontier-gpai/us/) | [欧盟](/topics/frontier-gpai/eu/) |
| --- | --- | --- | --- |
| 专门概念 | 无（靠"生成式 AI 服务"统摄） | 无（EO 14110 的 10²⁶ FLOP 已撤销） | **GPAI + 系统性风险 GPAI** 双档 |
| 算力门槛 | 无 | 无 | **≥ 10²⁵ FLOP** 推定 |
| 事前闸门 | 算法备案（面向公众必须） | 无 | 合规推定 + CE 标记 |
| 技术标准 | TC260-003-2024 | NIST AI RMF（自愿） | CEN-CENELEC 和谐标准 |
| 行为守则 | 无 | 白宫 Voluntary Commitments (2023) | Code of Practice (2025-05) |
| 罚则 | CSL 第 68 条 / 刑责 | 州法（参差） | 全球年营收 3%（GPAI） |

## 共同关切

- **算力阈值的合理性**：10²⁵、10²⁶ FLOP 是任意的吗？与能力的关系？
- **开源的特殊处理**：EU 有部分豁免，中国实务模糊，美国基本放任
- **系统性风险评估方法**：各公司 RSP / FSF / Preparedness Framework 是否足够？
- **国家安全 × 商业监管**的交织：出口管制、投资审查与 AI 监管的关系
