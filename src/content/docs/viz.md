AI 治理的规则叙事常常是文字密集的。本节提供**五个交互可视化**，把之前散在各页的
一手规则、数据、时间关系，转成可以一眼读懂的图。

## 技术说明

五张图均为**纯 Astro + SVG + CSS 实现**（无重量级 JS 依赖），数据来自
[`src/data/viz-data.ts`](https://github.com/3013038780-design/comparativeai/blob/main/src/data/viz-data.ts)。
可视化与内容页（Markdown）共享同一套语义色：

- **辖区色**：中国 朱砂 · 美国 藏青 · 欧盟 墨绿
- **位阶色**：五级位阶从朱砂到墨绿的渐变

所有图的数据计数都是**分析代理**（本站收录的主要一手规则数），不是穷举。
详见 [方法论 · 收录标准](/methodology/#inclusion)。
