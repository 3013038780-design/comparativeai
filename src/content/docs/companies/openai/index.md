## 公司概况

- **成立**：2015（非营利） → 2019（capped-profit 混合结构） → 2024-2025 公司重组
- **总部**：San Francisco, California, USA
- **主要模型**：GPT 系列（GPT-4o / o3 / o4 系列）、Sora、DALL-E
- **商业模式**：API、ChatGPT（消费者 / Plus / Team / Enterprise）、与 Microsoft Azure 深度整合
- **定位**：从"安全通用 AI 造福全人类"到"AGI 商业化加速者"的重心转移

## 监管合规位置

- **美国**：2023 White House Voluntary Commitments 签署方；Frontier Model Forum 创始成员；
  NIST AI RMF 采用者
- **欧盟**：GPAI Code of Practice **签署方**（2025-05，与 Meta 一样部分章节有异议记录）；
  与 Axel Springer、FT、News Corp 等欧洲媒体签署训练数据许可
- **中国**：**不在中国大陆提供服务**；通过 Azure 国际版 / 海外合作
- **意大利**：2023-03 曾被 Garante 临时封禁；2024-12 继续被 Garante 罚款（€15M）

## 公司立场速览

- 创办初期 "**AGI 造福人类**" vs. 2025 后 "**加速 / 国家主导权**" 的语言转向
- 对 EO 14179 的立场：**公开支持**
- 在美国以**州级立法**（加州 SB-1047）上**公开反对强制安全义务**
