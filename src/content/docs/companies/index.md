## 每家公司的收录结构

1. **Usage / Acceptable Use Policy** — 用户可否用模型做什么
2. **Model Card / System Card** — 模型能力、训练数据、评估
3. **Safety Framework** — 负责任扩展、准备度、前沿风险管理
4. **Transparency Report** — 定期披露（数据请求、内容审核等）
5. **Red-Team & Eval Disclosures** — 第三方评估与红队披露

每份材料都带 `snapshot_date`、原文链接、本站归档副本（PDF 存 `public/archives/`）。
**不做评判性表述**，只罗列原文关键条款与客观差异。
