## 公司概况

- **成立**：2010 (DeepMind) → 2014 被 Google 收购 → 2023 与 Google Brain 合并为 Google DeepMind
- **总部**：London, UK (DeepMind 起源) + Mountain View (Google)
- **主要模型**：Gemini 系列（Ultra / Pro / Flash / Nano）、Imagen、Veo、Lyria、
  AlphaFold（生物）、Project Astra（多模态代理）
- **商业模式**：Google Cloud Vertex AI、Gemini App、深度整合 Google 产品矩阵
- **定位**：与 Google 整体 AI 战略绑定；研究（AlphaFold / AlphaGeometry / AlphaProof）
  与产品（Gemini）并行

## 监管合规位置

- **美国**：2023 Voluntary Commitments 签署；Frontier Model Forum 创始成员
- **欧盟**：GPAI Code of Practice **签署方**（2025-05）；
  Gemini 系列作为高算力模型同时触发系统性风险义务
- **中国**：**不在中国大陆提供 Gemini 消费者服务**；Google Cloud 部分企业服务通过合作方
- **英国**：总部所在地；与 UK AISI 深度合作
- **印度 / 日本 / 巴西**：持续推进本地化合规

## 公司立场速览

- **Google AI Principles**（2018）为最早的公司级 AI 伦理原则之一
- 2024 **删除了对军事用途的排除** (争议)
- FSF 强调 "Critical Capability Levels" (CCL) 预测式评估
