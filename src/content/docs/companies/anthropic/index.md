## 公司概况

- **成立**：2021
- **总部**：San Francisco, California, USA
- **主要模型**：Claude 系列（当前 Claude Opus 4.7 / Sonnet 4.6 / Haiku 4.5）
- **商业模式**：API、Claude.ai、Claude Code、企业合作、AWS Bedrock / Google Vertex 分销
- **定位**：安全优先的前沿实验室（"Constitutional AI"、RSP 首创者）

## 监管合规位置

- **美国**：NIST AI RMF 采用者；2023 White House Voluntary Commitments 签署方；
  Frontier Model Forum 创始成员
- **欧盟**：GPAI Code of Practice **签署方**（2025-05 完整签署）；
  依 EU AI Act 第 53-55 条准备系统性风险评估文档
- **中国**：**未直接进入中国市场**；通过 AWS / 合作方的非公开渠道
- **英国**：AISI (UK) 的合作协议，模型预部署测试

## 公司立场速览

- 强调"**长期对齐 (alignment)**"和"**机制可解释性 (interpretability)**"研究
- 支持**强监管**但反对过度部门化 / 地方化
- 多次公开呼吁 frontier AI 的政府监管（创始人 Dario Amodei 2023 参议院证词）
