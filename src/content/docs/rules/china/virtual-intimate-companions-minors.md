## 可能的核心禁止内容（待校对）

以下是根据上位法反推的**可能规制内容**，均以官方原文为准：

1. **服务禁止**：禁止向未成年人提供以"虚拟恋人 / 伴侣 / 亲密关系"为核心交互的 AI 陪伴服务
2. **实名核验**：服务提供者须通过技术手段识别未成年人身份
3. **内容过滤**：即使成年人服务，涉及暧昧 / 情色 / 心理操纵类内容的训练和生成需单独评估
4. **防沉迷**：使用时长和消费限制
5. **监护人介入**：未成年人被识别后，触发向监护人通知
